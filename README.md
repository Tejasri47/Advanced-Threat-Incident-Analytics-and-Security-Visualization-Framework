# 🛡️ Cyber Threat Analytics and Security Visualization Framework

An interactive **Cybersecurity Incident Analytics Dashboard** developed using real-world cybersecurity incident data. The project focuses on analyzing attack patterns, attacker and actor behavior, targeted assets, countries, attack motives, and incident severity through interactive Power BI dashboards.

## 🚀 Key Features

📊 **Cybersecurity Incident Overview:**
Provides an executive-level view of total incidents, attack types, targeted countries, and global threat distribution.

🔍 **Attacker and Actor Intelligence:**
Analyzes actor types, attacker origins, attacker countries, and incident trends to understand who initiates cybersecurity incidents.

🧠 **Target and Asset Vulnerability Analysis:**
Identifies commonly targeted assets, asset varieties, attack details, attacker motives, and asset-related attack patterns.

⚙️ **Impact and Incident Severity Analysis:**
Examines attack details, asset environments, incident trends, cloud versus on-premise assets, and severity-related indicators.

📈 **Interactive Data Visualization:**
Uses charts, slicers, tables, maps, KPI cards, matrices, and trend visualizations to enable interactive exploration of cybersecurity incidents.

## 🛠️ Tools & Technologies

* **Power BI:** Dashboard development and interactive data visualization
* **Power Query:** Data cleaning, transformation, and preprocessing
* **DAX:** Calculated measures, KPIs, and analytical calculations
* **Microsoft Excel / CSV:** Data handling and supporting datasets
* **VCDB (VERIS Community Database):** Cybersecurity incident dataset used for analysis

## 📊 Project Workflow

**Data Collection** – Collected cybersecurity incident data from the VERIS Community Database (VCDB), containing detailed information about incidents, actors, actions, assets, motives, and victims.

**Data Cleaning & Preprocessing** – Cleaned and transformed the dataset using Power Query by handling missing and unknown values, standardizing fields, removing unsuitable records, and preparing data for visualization.

**Data Analysis** – Analyzed incidents based on attack type, actor type, attacker country, targeted assets, attack motives, year, and other cybersecurity attributes. DAX measures were used to calculate important metrics and KPIs.

**Visualization / Dashboard Development** – Developed multiple interactive Power BI dashboard pages covering executive summary, threat analysis, attacker and actor intelligence, target and asset vulnerability, and impact and incident severity.

**Insights & Interpretation** – Interpreted the visualized data to identify dominant attack types, major attacker origins, frequently targeted assets, common attack motives, geographical patterns, and changes in incident activity over time.

## 🎯 Objectives

* To analyze cybersecurity incidents using real-world incident data.
* To identify major attack types, attacker patterns, and targeted assets.
* To understand the geographical distribution of cybersecurity incidents.
* To provide interactive dashboards for effective threat analysis and decision-making.
* To demonstrate the practical application of **Power BI, Power Query, DAX, and cybersecurity analytics**.
